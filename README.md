# 巴菲特价值投资多智能体协作系统

## 项目简介

本项目是一个基于巴菲特价值投资理念的多智能体协作系统，通过模拟巴菲特的投资决策过程，对A股上市公司进行全面的价值投资分析。系统采用四个专业智能体协作的方式，分别从"好生意"、"好公司"、"好价格"三个维度进行并行分析，最后由决策智能体进行综合评估。

## 系统架构

### 核心设计理念

巴菲特的价值投资理念可以概括为三个核心要素：
1. **好生意（Good Business）**：具有强大护城河和持续盈利能力的商业模式
2. **好公司（Good Company）**：优秀的管理层和规范的治理结构
3. **好价格（Good Price）**：当前价格相对于内在价值具有足够的安全边际

## 智能体详细设计

### 1. 好生意智能体 (Good Business Agent)

**分析维度：**
- **护城河分析 (40%权重)**
  - 品牌护城河：品牌价值、消费者忠诚度
  - 成本护城河：规模经济、技术优势
  - 网络效应护城河：平台价值、生态系统
  - 转换成本护城河：客户粘性、系统绑定
  - 监管护城河：行业壁垒、政策保护

- **盈利稳定性 (30%权重)**
  - 收入稳定性：营收增长趋势、客户多样化
  - 利润质量：毛利率、净利率稳定性
  - ROE持续性：长期ROE表现、驱动因素

- **现金流生成能力 (20%权重)**
  - 自由现金流：经营现金流质量
  - 资本效率：资本支出需求、营运资金管理

- **行业前景 (10%权重)**
  - 行业增长性：长期发展潜力
  - 竞争格局：市场集中度、竞争优势

### 2. 好公司智能体 (Good Company Agent)

**分析维度：**
- **管理层质量 (40%权重)**
  - 诚信透明度：财务报告质量、信息披露
  - 资本配置能力：投资决策、股东回报
  - 战略执行力：战略规划、业绩兑现

- **财务健康度 (30%权重)**
  - 资产质量：资产结构、减值风险
  - 负债结构：债务水平、偿债能力
  - 盈利质量：利润真实性、会计稳健性

- **治理结构 (20%权重)**
  - 股权结构：股权集中度、利益一致性
  - 董事会治理：独立性、决策有效性
  - 内控体系：风险管理、合规监督

- **可持续发展 (10%权重)**
  - 创新能力：研发投入、技术转化
  - ESG表现：环境责任、社会责任

### 3. 好价格智能体 (Good Price Agent)

**分析维度：**
- **绝对估值分析 (40%权重)**
  - DCF估值：自由现金流折现模型
  - 资产价值：净资产、重置成本
  - 盈利估值：PE倍数、盈利增长

- **相对估值分析 (30%权重)**
  - 同行业对比：行业PE、PB对比
  - 历史估值：历史估值区间分析
  - 市场对比：相对市场估值水平

- **安全边际评估 (20%权重)**
  - 估值折扣：价格vs内在价值
  - 风险调整：各类风险的估值影响
  - 下跌保护：最坏情况价值保护

- **投资时机 (10%权重)**
  - 市场周期：当前市场环境
  - 催化剂：价值重估因素

### 4. 最终决策智能体 (Final Decision Agent)

**决策框架：**
- **权重分配**：好生意35% + 好公司35% + 好价格30%
- **决策矩阵**：
  - 强烈推荐 (8.5-10分)：三项均优秀
  - 推荐 (7.0-8.4分)：整体良好
  - 谨慎推荐 (5.5-6.9分)：存在不足但有机会
  - 不推荐 (0-5.4分)：不符合价值投资标准

## 安装与配置

### 1. 环境要求
- Python 3.8+
- 有效的Tushare Pro账户和Token
- OpenAI API Key (或其他支持的LLM API)

### 2. 安装依赖
```bash
pip install -r requirements.txt
```

### 3. 配置设置
编辑 `config/config.yaml` 文件：

```yaml
api_keys:
  # 在 https://tushare.pro/ 注册获取
  tushare_token: "your_tushare_token_here"
  # OpenAI API Key
  openai_api_key: "your_openai_api_key_here"

llm_config:
  provider: "openai"
  model: "gpt-4"
  temperature: 0.1
  max_tokens: 32768

scoring_weights:
  good_business: 0.35
  good_company: 0.35
  good_price: 0.30
```

- `results/{股票代码}/price_analysis.json`：好价格智能体分析

## 评分体系

### 评分标准 (0-10分)
- **9-10分**：优秀，强烈推荐，符合巴菲特投资标准
- **7-8分**：良好，推荐，具备投资价值
- **5-6分**：一般，谨慎推荐，存在一定不足
- **3-4分**：较差，不推荐，存在明显问题
- **0-2分**：糟糕，回避，存在重大缺陷
